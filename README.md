# 🚌 LPU Campus Shuttle — Seat Request System

**Academic Project** · Lovely Professional University, G.T. Road, Phagwara, Punjab (India) — 144411
**Team:** Vasu · Aditya Chauhan · Krishna Yadav
**Session:** Academic Year 2026–27

A web-based portal for booking shuttle seats anywhere inside the 600-acre LPU campus — all gates, hostels, academic blocks, schools and facilities.

---

## ✨ Features

- 📊 **Live Dashboard** — total, confirmed and pending requests, available seats, total fare
- 🎯 **100+ Campus Locations** — every gate, hostel (BH 1–13, GH 1–6), Block 1–55, school and facility
- 🕐 **5 Daily Time Slots** — 8:00 AM, 9:00 AM, 1:30 PM, 5:00 PM, 6:00 PM
- 💺 **Seat Availability** — 20 fixed seats per shuttle trip, checked live before confirming
- 💰 **Transparent Fares** — ₹15 per seat per trip · ₹5 extra for luggage
- 🆔 **Unique Request ID** — e.g. `REQ-1001` with live status
- 📋 **Request Register** — search by name/roll number, filter by route & status, cancel anytime
- ⚙️ **Smart Status Logic** — 5+ seats → `Pending` for approval, otherwise `Confirmed`
- 📱 **Fully Responsive** — mobile, tablet and desktop
- 🔒 **Privacy First** — no server, no signup; data stays in the browser

---

## 🛠 Tech Stack

**HTML5 · CSS3 · Vanilla JavaScript · Browser localStorage**

> No build step, no dependencies — just open the file.
